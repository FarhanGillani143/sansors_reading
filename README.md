# Sensor Readings

This app will be used to read sensors data from mobile devices

## Steps to Reproduce

Make sure you've NodeJS installed on your device. Use following commands to reproduce the project on your machine

```
git clone https://github.com/ictgrid/sensor-readings.git
cd sensor-readings
npm install
```

Now use following commad to run the project on simulator or real device

```
npx expo start
```
